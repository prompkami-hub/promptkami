# 🎬 【田园牧歌·第一人称种田文】46.25秒全套提示词库 (保姆级实操手册)

> **产品简介**
> 这是一个开箱即用的AI视频工作流。包含完整20镜的文生图、图生视频提示词，以及详细的剪辑拼接参数。
> 本片最核心的手艺不是风景，而是**第一人称视角**：全片约一半镜头让"自己的手/手臂"主动伸进画面前景（举莲蓬、垂自己的双脚、伸手入溪、端饭碗、持折扇、自拍臂展），观众因此变成了走在村里的那个人。这条"把手伸进画面"的规则已写进每一镜的提示词里，是整条片子的灵魂。
>
> **🧰 推荐工具栈：**
> *   **文生图 (选其一)：** Midjourney / 即梦 / Flux / 星流
> *   **图生视频 (选其一)：** 可灵 / 即梦 / Vidu / 海螺
> *   **剪辑：** 剪映 (CapCut)

## 🛠️ 第一步：全局基础设定 (每次生图必备)

为了保证视频的画面统一性和风格连戏，请务必在每次生成图片时带上以下参数。

### 🚫 通用负向提示词 (Negative Prompt)
*用法：直接复制粘贴至工具的"负向提示词/排除词"输入框中。*
```text
现代服装, 现代建筑, 电线, 塑料制品, 塑料感, 劣质3D卡通, 畸形手指, 多指, 六指, 断肢, 手部穿模, 面部扭曲, 五官不对称, 文字, 字幕, 招牌文字, 水印, logo, 模糊, 噪点, 过曝死白, 高饱和艳俗, 冷蓝色调, 阴天平光, 广角畸变, 杂乱背景, 游客, 现代农机, copyrighted franchise character, named existing anime or game character, recognizable trademarked mascot, celebrity likeness, real brand logo
```

### 🌾 田园世界全局样式常量
*用法：把这一段接在每一镜文生图提示词的末尾，用来锁住全片的世界观、光线与色调。*
```text
中式南方山村田园，层层梯田沿山坡铺展，黛瓦木构老屋与石板小径，溪流穿村而过，石拱桥与垂柳，远山笼薄雾，低垂暖金色夕阳侧逆光，空气中浮尘与炊烟，整体暖金+青绿低饱和胶片调，轻微镜头光斑与边角失光，电影级写实渲染，浅景深 f1.8，9:16竖屏，8K超清，电影调色
```

### 🤲 第一人称视角与服化道全局样式常量
*用法：同上，每一镜都带。这一段决定了"这是我在村里"而不是"我在看风景照"。*
```text
第一人称主观视角，拍摄者自己的手或手臂自画面下缘或侧缘伸入前景并明显近于焦平面因而轻微虚化，手腕袖口为素色麻质汉服窄袖，画面中其他人物穿素色与淡彩麻质汉服襦裙、布鞋或赤足，发式为简单发髻或垂髫，无现代配饰，人物多为少女与老者，神情自然松弛带笑意，被摄者会看向镜头并与拍摄者互动
```

## 🎞️ 第二步：分镜逐帧实操 (20镜全量)

*操作指南：按照顺序，先复制【图】提示词生成静态图像，然后将满意的图像导入视频大模型，复制【动】提示词生成视频片段。*
*本片无任何对白与字幕，所以每一镜给的是动作描述而非台词。*

## 💡 附赠技巧

1.  **"把手伸进画面"是这条片子最值钱的一句话。** 20 镜里有 11 镜让拍摄者自己的手或手臂主动入画（举莲蓬、垂双脚、伸手入溪、衣袖扫镜、按宣纸、握风筝线、端饭碗、持折扇、自拍臂展×2、跟随步行）。新手拍同题材只会拍"好看的田园风景"，结果像一组旅游照；一旦每镜都有自己的手在前景且明显虚化，观众立刻从"看风景"变成"我在那里"。提示词里那句"自己的手自画面下缘伸入前景并明显近于焦平面因而轻微虚化"不要删——**虚化**这个词是关键，手拍得清清楚楚反而会假。

2.  **同机位拍第二拍，是把 4 秒素材变成 6 秒的省钱办法。** 镜 2/3、镜 13/14、镜 16/17 是三组同机位第二拍：同一个场景只改太阳高度、手的位置或镜头抬升幅度，就能再出一段。单段图生视频通常只能稳定生成 4-8 秒，这个办法让你在不增加生成次数的前提下把一个场景的时长翻倍，而且因为是同机位，用 0.2 秒叠化相接完全看不出接缝。

3.  **全片靠"低角度暖金逆光"统一，这比统一人物更重要。** 这条片子是群像而非单一主角——少女们在不同镜头里其实并不是同一张脸（镜 8 的浣衣少女、镜 18 的自拍少女、镜 20 的收尾少女各不相同），但没人会觉得出戏，因为**光线和色调是严格统一的**：全片一律低角度暖金侧逆光、青绿+暖金低饱和胶片调、带镜头光斑与边角失光。所以这类田园群像片不必死磕角色一致性，把"暖金色低角度侧逆光 + 浅景深 + 光斑"这组词固定在每一镜里，统一感自然就有了。
