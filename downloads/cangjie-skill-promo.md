# 🎬 【仓颉Skill开源项目宣传片】67秒代码渲染全套复刻手册 (保姆级实操手册)

> **产品简介**
> 这是一支由 Claude Opus 5.5 一句话直出的产品动效宣传片：画面与配乐全部由代码生成（HTML/CSS/Canvas 动效 + Web Audio/音乐库 BGM，录屏导出），**不含任何扩散模型图生视频素材**。本手册把它拆成可复刻的渲染函数、动效参数与录屏拼接参数。
>
> **🧰 推荐工具栈：**
> *   **代码生成 (选其一)：** Claude Opus 5.5 / Claude Code / GPT-5 (Canvas) / Gemini 3 Pro
> *   **渲染环境：** 浏览器 (Chrome/Edge) + 本地 HTML 文件，或 Remotion / p5.js 沙箱
> *   **录屏与剪辑：** QuickTime 屏幕录制 / OBS -> 剪映 (CapCut) 或 Premiere

## 🛠️ 第一步：全局基础设定 (每次渲染必备)

全片只有一套视觉系统：深色背景 + 单一品牌红 + 等宽/衬线混排字体 + 固定四角 HUD 取景框。没有人物、没有实拍素材，所以不需要"基准脸"，需要的是本节下方两块样式常量与固定 HUD 层，这是保证 28 个画面在视觉上"连戏"的关键。

### 🚫 通用负向提示词 (Negative Constraints)
*用法：写进渲染脚本的全局 CSS/Canvas 配置里，作为硬性排除项，不要出现在任何一帧。*
```text
真人实拍素材, 扩散模型生成图像, 人脸, 卡通形象, 高饱和多色配色, 衬线以外的手写字体滥用, 画面抖动模糊, 低分辨率像素化, 非4:3/16:9标准比例, 转场使用方框故障抖动以外的其他花哨特效, 背景出现与仓颉项目无关的品牌标识
```

### 🎨 全局样式常量 1：配色与字体 (调色板基准)
*用法：定义为 CSS 变量 / Canvas 全局常量，所有分镜共用，不单独声明。*
```text
背景色 #0a0a0a 到 #050505 纯黑渐变, 品牌强调色暗红 #c0392b 到 #8e2a1f 径向光晕(呼吸式明暗脉动), 主标题字色米白 #f0ead6, 次要文字字色灰 #6b6b6b, 等宽字体(类 JetBrains Mono / Söhne Mono)用于编号/时间码/英文小标题, 衬线字体(类 Noto Serif SC)用于中文大字"仓颉"及正文, 全片9:16或16:9视频比例(本片为720x744接近1:1), 画面四角固定取景框线(像电影遮幅取景器), 顶部状态栏(左侧栏目名+右侧阶段序号), 底部时间码+小节号+横向进度刻度条
```

### 🧩 全局样式常量 2：固定 HUD 叠层 (每帧不变层)
*用法：作为独立于内容层之上的 overlay 层渲染，全片位置、字体、不透明度保持像素级一致（这是本片区别于任何视频拍摄/生成素材的核心特征）。*
```text
左上角文字"CANGJIE SKILL — RIA-TV++"(等宽小字,灰白色,8-10px), 右上角文字"<罗马数字阶段> · <阶段中文名>"(如"II·溯源"/"IV·生态"), 左下角文字"<时间码 00:MM:SS> BAR <小节号> · 1"(等宽字体,随BGM小节单调递增), 右下角横向点阵进度条(4个圆点,当前阶段点为实心红色), 四角细线取景框(L形转角标记), 顶部与底部各留等高黑边(letterbox)
```

## ✂️ 第三步：后期录屏与拼接参数

当所有分镜片段在浏览器/渲染环境里逐一录制完毕后，按以下标准剪辑拼接：

| 参数项 | 设置标准 (照做即可) |
| :--- | :--- |
| **帧率与录屏设置** | **硬切 (0转场)。** 每镜固定时长直接拼接，不加叠化/黑场。录屏固定 30fps，分辨率固定 720×744（或等比例容器），避免拼接时出现帧率/尺寸跳变。 |
| **时长节奏** | **文字过渡镜（第2-5、9-10、19-21镜）：** 2s 一镜，靠文字切换本身制造节奏。<br>**阶段卡镜（第12-18镜）：** 2s 一镜，统一节奏感模拟"流水线"推进。<br>**定格/收尾镜（第26-28镜）：** 2-4s，逐步减速，营造收尾停顿感。 |

## 💡 【附赠】买家专属高阶技巧
1.  **关于 HUD 固定层的实现：** 四角取景框、顶部栏目名、底部时间码/进度条应作为独立于内容层之上的 overlay 组件渲染（CSS `position: fixed` 或 Canvas 单独图层），只在视频开场渲染一次位置和样式，后续每镜只更新文字内容（阶段序号、时间码数值），不要重新定位整个 HUD —— 这是保证全片 24 镜在像素级别"连戏"的核心，本片实测该层在不同时间点 SSIM = 1.000000（逐像素完全一致）。
2.  **避免动效穿帮：** 本片几乎不用复杂物理动画，全部是淡入/滑入/缩放弹跳/数字滚动/路径描边这几种基础 CSS/SVG 动效的组合复用。复刻时不要追求炫技运动，统一动效语言比炫技更重要，这正是"审美高级感"的来源。
3.  **BGM 卡点优先于画面卡点：** 本片的"卡感"主要靠 BGM 的 BAR 节拍驱动镜头切换时机，而不是画面本身有运镜。建议先选定 BGM 并标出小节重音时间点，再把分镜时长对齐到小节边界，而不是先定镜头时长再找配乐凑。
