## 🛠️ 第一步：全局基础设定 (每次生图必备)

本片是云端天宫建筑/奇观展示向短片，人物均为远景比例尺点缀（不做脸部特写），因此全局设定以**场景风格常量**替代传统基准脸，保证每镜建筑质感、云海色调、人物服装统一。

### 🚫 通用负向提示词 (Negative Prompt)
*用法：直接复制粘贴至工具的"负向提示词/排除词"输入框中。*
```text
现代服装, 现代建筑, 玻璃幕墙, 塑料感, 动漫, 3D卡通, 畸形建筑结构, 文字错乱, 牌匾文字, 水印, logo, 模糊, 噪点, 过曝死白, 冷蓝色调, 广角畸变, 杂乱背景, 人物面部特写, 真实人物肖像
```

### 🏯 天宫建筑全局样式常量 (垫图用)
*用法：先用此提示词生成一张满意的建筑云海图，保存下来。后续每一镜的宫阙/云海画面，都将此图作为"参考图/垫图"放入AI工具中。*
```text
悬浮云端的中式仙宫建筑群，白玉石雕栏与朱红描金立柱，古松虬枝悬挂藤蔓垂落，云海翻涌至天际线，古装仙侠电影级写实渲染，9:16竖屏，强逆光体积光，柔光溢出与雾化高光，米白+朱红+金色调，8K超清，极致石雕与木构细节，电影调色
```

### 🧍 远景人物全局样式常量 (垫图用)
*用法：同上，作为每镜中点缀性古装人物的参考垫图，人物始终为中远景背影或侧影，不做面部特写。*
```text
三至四名古装仙侠人物远景背影，男款月白/墨色广袖长袍，女款月白/浅粉/浅青纱裙披帛，黑发简束，站立或端坐于白玉栏边，比例占画面不超过十分之一，古装仙侠电影级写实渲染，9:16竖屏，柔光逆光，8K超清
```

## ✂️ 第三步：后期剪辑与拼接参数

当所有视频片段生成完毕后，导入剪映按以下标准进行组装：

| 参数项 | 设置标准 (照做即可) |
| :--- | :--- |
| **转场特效** | **硬切 (0转场)。** 依靠镜头内运动（推/摇/跟随）与奇观构图自然过渡，个别镜头（第8、14、19、21、26、27镜的倒悬宫殿）可叠加极轻微的垂直翻转/溶解特效強化"天地倒悬"奇观感。 |
| **时长节奏** | **开场定场镜头：** 第1镜独占约30s作为引子，其余按原片实测切点截取（2.5-7s不等）。<br>**奇观强调镜头：** 第8、9、14、19、21、25镜（倒悬/异构建筑）可适当拉长1-2s强化视觉冲击。 |
| **字幕样式** | 本片无对白字幕，画面干净。如需添加标题文案，建议居中偏上，白色细体中文书法字体 + 淡金色渐变，配合古风印章小图标。 |
| **BGM (配乐)**| 选取"古风笛箫 + 空灵女声吟唱 + 低频环境音"类型配乐。**关键：在第 48s 处 (画面首次垂直倒悬翻转时) 音量与低频鼓点微微抬升，强化奇观冲击；第 136s 处 (岩浆湖段) 转为更空灵/诡丽的音色过渡。** |
| **导出画质** | 尺寸：`1280 × 720` (16:9横屏，原片实测) <br> 帧率：`30 fps` <br> 格式编码：`H.264 + AAC` <br> 码率推荐：约 `1.4 Mbps` |

## 💡 【附赠】买家专属高阶技巧
1.  **关于"倒悬天宫"奇观的复刻：** 本片标志性的建筑倒影/倒悬效果，可在生成正常构图的宫殿图后，用剪辑软件做局部垂直翻转叠加合成，比直接让AI生成"倒悬建筑"更稳定、细节更可控。
2.  **避免建筑细节崩坏：** 本类纯风光/建筑向视频最大的坑是雕刻纹样、牌匾文字和屋檐重复结构在AI生成时容易出现"类文字却不成字""斗拱节奏错乱"的瑕疵，生成后务必放大检查重点建筑细节区域，发现崩坏及时重新生成该图层。
3.  **人物比例克制：** 全片人物均为远景点缀，不要贪心加入人物面部特写——这类纯景观向短片的卖点是建筑与云海的宏大感，人物特写反而暴露AI人脸生成的瑕疵，拉低整体质感。
