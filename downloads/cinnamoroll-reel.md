# 🎬 【玉桂狗动效简历 MOTION REEL】15秒全套代码提示词库 (保姆级实操手册)

> **产品简介**
> 这是一个开箱即用的代码动画工作流。包含完整10镜的渲染函数、动效参数提示词，以及详细的录屏拼接参数。
> 本片不是扩散模型视频，而是浏览器里用代码渲染后录屏而成——所以交付的是写代码的提示词，不是文生图提示词。
>
> **🧰 推荐工具栈：**
> *   **写代码 (选其一)：** Claude / Claude Code / Cursor / 任意能写 HTML+Canvas 的模型
> *   **渲染预览 (选其一)：** Chrome / Edge / Arc / Safari 技术预览版
> *   **录屏 (选其一)：** OBS Studio / Chrome DevTools Recorder / ScreenStudio / QuickTime
> *   **剪辑：** 剪映 (CapCut)

---

## 🛠️ 第一步：全局基础设定 (每段渲染必备)

本片的统一感全靠三件事：一套固定调色板、一个贴在最上层永不重建的 HUD、一张角色 PNG 资产。先把这三样定下来，后面 10 段只改中间的画面层。

### 🚫 通用负向提示词 (Negative Prompt)
*用法：直接粘贴到写代码的对话里，作为整个项目的硬约束。*
```text
不要引用任何外部 CDN 或网络字体, 不要依赖 WebGL 或 three.js, 不要用 setTimeout 串联时间轴, 不要动 width/height/top/left 等触发重排的属性, 不要在字体加载完成前开始动画, 不要引入 GIF 或视频素材, 不要使用未固定种子的 Math.random, 不要让 HUD 层随 section 重建, 不要用 JPEG 角色图 (必须带透明通道的 PNG), 不要出现滚动条, 不要让画布尺寸随窗口变化, 不要超过 30fps 的重绘循环
```

### 🎨 全局样式常量 A：调色板与排版 (所有段落复用)
*用法：先让模型把这段写成一个 `tokens.js` 常量表，后面每一段都从这里取色，禁止临时写死十六进制。*
```text
生成一份动效项目的设计 token 常量表, 命名 tokens.js, 导出以下常量: 调色板 BLUE #2B3FE8 / RED #EE4126 / YELLOW #E8AE1C / PINK #F07CA8 / LAVENDER #B298FA / CREAM #EFEBE2 / INK #080A18 / GREEN_SCREEN #4CAF2F, 标题字体为超粗无衬线 (Inter Black 或 Helvetica Now Black) 字重 900 字距 -0.02em, HUD 字体为等宽 (JetBrains Mono 或 IBM Plex Mono) 字号 11px 字距 0.12em 全大写, 装饰标签字体为衬线斜体 (Playfair Display Italic), 画布固定 1280x720 不随窗口变化, 全局节拍 BPM=150 即每拍 0.4 秒, 所有缓动统一用 cubic-bezier(0.22,1,0.36,1), 所有动画只允许改 transform 和 opacity
```

### 🖥️ 全局样式常量 B：HUD 固定框架 (贴在最上层，全片不重建)
*用法：这一层只创建一次，之后 10 段都在它底下换画面。TC 必须用时钟驱动，不要逐段手写数字。*
```text
生成一个固定在最上层的 HUD overlay 层, 1280x720 绝对定位 pointer-events none, 包含五个元素: 四角 1px L 形括号边长 22px 内缩 22px, 左上角 section 标签格式为两位数字加斜杠加全大写英文名 (如 03 / TIME ECHO), 右上角固定文字 CLAUDE - MOTION REEL 2026, 左下角时间码 TC 00:00:SS:CC 其中 CC 是百分之一秒 由 performance.now() 驱动每帧更新 格式化为两位补零, 右下角文字 150 BPM 后跟四个 8px 方块作为节拍指示器 当前拍为实心其余空心 每 0.4 秒循环推进一格, HUD 文字颜色随当前段落背景自动取对比色 (浅底用 INK 深底用 CREAM 黄底用 BLUE), 整层在第 0.8 秒淡入 0.3 秒
```

## 💡 【附赠】买家专属高阶技巧
1.  **HUD 只创建一次，时间码必须用时钟驱动。** 把 HUD 做成独立的 overlay 层，`position:fixed` 贴最上层，10 个段落都在它底下换画面。时间码用 `performance.now()` 换算成 `SS:CC` 格式化输出，**千万不要逐段手写数字**——手写的数字一旦和实际播放时长错位，整条片子的「专业感」立刻崩掉，而观众恰恰最爱盯这个数字看。
2.  **角色只准备一张 PNG，所有风格都靠后处理派生。** 半调、ASCII、贴纸、蓝图这四种看起来完全不同的渲染，全部由同一张带透明通道的角色图经 canvas 后处理生成（取明度映射字符 / 画网点 / 加描边 / 抽轮廓）。这是本片连戏感的真正来源——换成四张分别生成的图，角色比例和姿态一定会漂。
3.  **每段写成独立函数 + 统一时间轴驱动。** 用一个总时间轴 `t` 调度 10 个 `sceneXxx(t)` 函数，段落边界写成常量数组。这样录屏掉帧时只需重录那一段，不用整条重来；调节奏时也只改边界数组，不碰渲染代码。所有动画只允许改 `transform` 和 `opacity`，一旦动了 `width` 或 `top` 就会触发重排，30fps 必掉。
