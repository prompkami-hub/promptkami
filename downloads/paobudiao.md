## ✂️ 第三步：后期剪辑与拼接参数

将各镜生成的图生视频片段按顺序拼接，注意情绪特写镜的节奏控制。

| 参数项 | 设置标准 (照做即可) |
| :--- | :--- |
| **转场特效** | 镜1→2、镜5→6 用溶解转场(0.3-0.4s)；其余镜头硬切，镜10-14快切簇间隔≤0.5s保持紧张感 |
| **时长节奏** | 镜1、镜5、镜14、镜17 为情绪特写，适当放慢节奏停留；镜10-14 快切簇(16.9-19.43s)保持原速制造压迫感 |
| **字幕样式** | 白色描边宋体，画面下方约80%高度居中，镜5-14(8.33-19.43s)多为动作描述无字幕，不强行补字 |
| **BGM (配乐)** | 0-8s 轻柔古风弦乐铺底；8s(镜6血迹揭露)骤转低沉；15.6s(镜9黑袍逼近)鼓点渐强；19.43s(镜15强留)音量拐点推至最高并保持到结尾 |
| **导出画质** | 1080x1920，30fps，H.264编码，码率≥2.5Mbps（与原片2.51Mbps实测一致） |

## 💡 【附赠】买家专属高阶技巧
1.  **溶解转场复刻换景感：** 镜5→6 的身份反转（侧脸老者→男主抬眼见血）用 cross-dissolve 而非硬切，才能复现"信息延迟揭露"的悬疑感，硬切会丢失原片的叙事节奏。
2.  **快切簇密度决定情绪张力：** 镜10-14 五个镜头压缩在约2.5秒内（16.9-19.43s），每镜0.47-0.56秒，剪辑时务必卡紧节奏，拖长任何一镜都会削弱"猎物被逼近"的压迫感。
3.  **逆光+暖色灯笼是本片基调锁：** 全片17镜中有10镜以上用暖色侧逆光+虚化灯笼光斑，生图时固定这一光源逻辑，才能让17镜拼接后色调统一不跳帧。
