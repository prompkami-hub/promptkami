> **产品简介**
> 这是一个开箱即用的"代码动画"工作流（Canvas/SVG 纯矢量渲染，视频内自带字幕"Every plate is drawn live in JavaScript · No images."）。包含完整20镜的渲染函数、动效参数，以及详细的录屏剪辑拼接参数。
>
> **🧰 推荐工具栈：**
> *   **渲染环境 (选其一)：** Claude (Artifacts/Canvas) / p5.js + 浏览器 / HTML5 Canvas 自写脚手架 / Remotion
> *   **动效驱动：** CSS transform + requestAnimationFrame 匀速滚动 / GSAP timeline
> *   **录屏与剪辑：** OBS Studio (录屏) → 剪映 / CapCut (拼接导出)

### 🎨 全局样式常量 (卡牌排版系统，垫图用)
*用法：先用此参数集固定"展牌"的通用 DOM/Canvas 结构（卡片比例、序号字体、标题字体、分隔线），后续每一镜只替换卡内插画与底部图注文字，排版框架保持像素级一致。*
```text

```

## 💡 【附赠】买家专属高阶技巧
1.  **匀速滚动是全片"眩晕感"的核心机制：** 20张风格迥异的卡片以恒定线性速度（无缓动曲线）连续横移约38秒，观众视觉系统持续追踪高频率切换的色彩/构图/字体，产生信息过载式的轻微眩晕感，复刻时务必保证滚动速度全程恒定、不做任何缓入缓出，否则眩晕效果会被稀释。
2.  **每张卡片必须是独立画幅，不共享像素层：** 实测每张卡片内部的插画与前后相邻卡片完全独立渲染（无共享背景、无跨卡渐变），这是区分"真实镜头运镜"与"UI网格横向滚动"的关键特征，复刻时建议用CSS flex横排容器+独立子元素渲染，而非单张超宽画布平移。
3.  **终局网格汇聚动效是唯一的"节奏变速点"：** 全片仅在最后约6.5秒（镜20发散+归位网格+标题淡入）才出现非线性缓动动效，前19镜全部保持匀速。这种"长时间匀速铺垫+结尾一次性变速收束"的节奏设计，是让"眩晕感"在结尾转化为"豁然开朗/一览全貌"式满足感的关键，复刻时务必把变速动效严格限制在片尾，不要提前使用。
